# vibeplane

**Vibeplane** is a local-first control plane for AI coding agents — Claude Code first, Codex and OpenCode next.

One board across all your projects and providers, an attention inbox that only shows what needs a human, work items with verification gates ("verified done", not "agent says done"), and Git/GitHub integration. Rust core, React UI, no cloud account.

This crate is a **placeholder release that reserves the name** while the product is built. Concept, architecture and roadmap: <https://github.com/hupe1980/vibeplane>.

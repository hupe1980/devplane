Vibeplane is one binary. It watches the agent sessions already running on your machine, drives new
ones over a documented protocol, and refuses to call work finished until the commands your
repository committed agree that it is.

Start with the [quickstart](/docs/quickstart/) — it takes about a minute and needs no configuration.
